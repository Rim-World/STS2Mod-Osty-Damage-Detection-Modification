# 1.0（2026-08-15）

- **版本号**：1.0
- **时间戳**：2026-08-15（`1.ADR/003-构建与安装.md` 记录当日构建安装完成；远端首个源码提交 `0a34f52` 时间 2026-08-15 20:20:38 +0800）
- **开发人员反馈**：构建 0 警告 0 错误，产物已安装到游戏 `mods\OstyDamageDetectionMod`（dll / pdb / json / pck 齐全）。实机验证尚未进行，当时的待验证项为：启动日志补丁计数、mod 列表图标、场景 A（化石追踪者）、场景 B（盛碗虫·石）、无奥斯提回归。
- **实装更改概括**：
  - 新增独立 mod `OstyDamageDetectionMod`（作者「再玩小卡组找人弄你」，版本 1.0）。
  - 修正化石追踪者 `SuckPower` 的受击判定：攻击被奥斯提完全吸收时不再加力量，被击穿、玩家真实掉血时照常加力。
  - 修正盛碗虫·岩石变体 `ImbalancedPower` 的受击判定：攻击被奥斯提完全吸收时触发失衡并在下回合晕眩，被击穿时继续进攻。
  - 未召唤奥斯提时，两个怪物的行为与原版完全一致。
  - 附带 mod 列表图标（`res://OstyDamageDetectionMod/mod_image.png`），为此将清单改为 `has_pck: true` 并由构建生成 pck。
- **简略技术细节**：
  - 采用 Harmony 两个 Prefix 补丁，`return false` + `ref Task __result` 整体替换 `SuckPower.AfterAttack` 与 `ImbalancedPower.AfterDamageGiven` 两个 async 方法，不改写 `DamageResult` 数据。
  - `SuckPower.AfterAttack`：把原版「移除主人结果、只看宠物结果」反转为「移除宠物结果、只看主人结果」，宠物判定用通用属性 `Receiver.IsPet`。
  - `ImbalancedPower.AfterDamageGiven`：在 `result.WasFullyBlocked` 之外新增「宠物结果 `UnblockedDamage > 0 && OverkillDamage == 0`」即视作完全格挡。
  - 不使用 `PatchAll` 特性自动发现，改为反射 `GetMethod` + 手动 `harmony.Patch`，方法缺失时跳过并记 Warn，因此不设 `min_game_version`（兼容 107 / 110 / 111）。
  - `PowerModel.Flash()` 为 protected，经 `PowerModelExtensions.FlashSafely()` 反射调用，失败静默忽略。
  - 构建链路：`Godot.NET.Sdk/4.5.1` + `net9.0`，引用游戏目录 `sts2.dll` / `0Harmony.dll`（`Private=false`）；`build.ps1` 依次执行 `dotnet build` → Godot `--import` → Godot `--export-pack` → 拷贝产物到游戏 mods 目录。
  - 安装产物：`OstyDamageDetectionMod.dll` 13312 B、`.pdb` 14216 B、`.json` 664 B、`.pck` 269392 B。
- **失败经验或实验教训**：
  - 放弃「路线 A：改 `CreatureCmd.Damage` 的 `wasFullyBlocked` 语义」——`Hook.AfterDamageGiven` 在方法内部执行，Postfix 无法影响，async 方法无法中间插入，整体替换需复刻约 100 行逻辑且跨版本签名不同。
  - 放弃「路线 B：补丁 `Hook.AfterDamageGiven` 分发器」——单条结果无法区分「被奥斯提吸收」与「0 伤害攻击」，两者在玩家结果上表现相同。
  - 编译期踩坑：`SuckPowerAfterAttackPatch` 缺少 `MegaCrit.Sts2.Core.ValueProps` 的 using（`IsPoweredAttack` 扩展方法）；`Flash` 反射调用需按 nullable 标注处理（CS8601）。
  - 初版清单为 `has_pck: false` 且构建省略 Godot 步骤，结果 mod 列表无图标；补做 `project.godot` 与 `export_presets.cfg` 后才恢复 `--import` / `--export-pack`。
