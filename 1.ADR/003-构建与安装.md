# ADR-002：奥斯提受击判定修复 mod 构建与安装

- 日期：2026-08-15
- 状态：**已实施**（构建成功、已安装；实机验证待用户）

## 决策

1. **独立新 mod**：id `OstyDamageDetectionMod`；文件夹与 id 同名；name「奥斯提受击判定修改Osty Damage Detection Modification」；author「再玩小卡组找人弄你」；version 1.0；description 为用户定稿文案（强调非单怪修改、对未来同逻辑怪物生效）。
2. **manifest**：`has_pck: false`（纯逻辑无素材）、`has_dll: true`、`affects_gameplay: true`、**不设** `min_game_version`（兼容 107/110/111）。
3. **构建链路沿用现有方案**：Godot.NET.Sdk/4.5.1 + net9.0，引用本地 `sts2.dll`/`0Harmony.dll`；因无 pck，build.ps1 省略 Godot import/export，仅 `dotnet build` + 拷贝 dll/pdb/json 到 `mods\OstyDamageDetectionMod`。
4. **补丁应用方式**：放弃 `PatchAll` 特性自动发现，改**手动 `harmony.Patch` + 反射 GetMethod**——方法缺失时逐个跳过并记 Warn（仅反射存在性兜底，用户拍板）。
5. **`PowerModel.Flash()`（protected，PowerModel.cs:450）**：补丁外不可直接调用，经反射 `FlashSafely()` 扩展调用，失败仅丢失视觉闪烁不影响功能。
