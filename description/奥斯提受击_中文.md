# 如果你喜欢本mod，也欢迎看看我的其它mod。或许对你有帮助。

## ① 效果

修改亡灵契约师的宠物奥斯提（Osty）吸收伤害时的逻辑：

- 攻击被奥斯提完全吸收（玩家未掉血）时，化石追踪者（Fossil Stalker）不再吸取加力；
- 攻击被奥斯提完全吸收（玩家未掉血）时，盛碗虫（石）（Bowlbug Rock）会正确触发失衡，下回合晕眩；
- 奥斯提被击穿、玩家真实掉血时，以上两怪保持原版行为（化石追踪者照常加力、盛碗虫不晕眩）；
- 无奥斯提（未召唤）时两怪行为与原版完全一致。

## ② 影响（基于本人游戏理解）

整体略微提升亡灵契约师职业的强度，几乎不影响游戏数值平衡。

具体来讲，在单人a10 SL（save&load）模式，亡灵契约师职业的强度依然在五个职业中排行第四或第五；

其强度与排行第三的储君依然有较大差距，与排行前二的铁甲战士、静默猎手有极大差距。

本 mod 不修改任何怪物、任何卡牌、任何数值，对存档无影响，关闭 mod 后立即恢复原状。

## ③ 环境与版本

本 mod 不依赖任何基础 mod，支持 default 107、public beta 111 版本。

游戏启动时 mod 会检测当前游戏包体内“化石追踪者吸取”与“盛碗虫失衡”两个机制是否存在；

若未来版本改动了相关机制导致无法找到，mod 会自动跳过对应部分并仅记录日志，不会报错或崩溃。

理论上只要没有大的 api 更新或相关机制修改，本 mod 无须修改即可自动适配新版本。

## ④ 语言支持

本 mod 是纯逻辑修改，不包含任何文本内容，对所有语言均同样生效。

## ⑤ 实现方式与兼容性

本 mod 通过修改游戏内两个机制（吸取判定、失衡判定）实现，未来采用相同逻辑的新怪物会自动沿用修正后的判定，但设计新机制的怪物则需要进行额外适配。

本 mod 采用最小依赖的方式写成，正常来说与大多数 mod 兼容，且不易随着 beta 新版本更新而失效。

但本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。
